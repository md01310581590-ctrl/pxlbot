# 👾 PxlBot Studios // Официальный бот студии (v2.0 Market Edition)

Интерактивный бот для презентации проектов студии (включая флагманы «Агротерминал», «Агротрейд» и «ЮрБиржа»), рыночной тарифной сетки, контура сопровождения SLA & Growth (`5 900 / 12 900 / 24 900 ₽/мес`), реанимации чужих ботов, 3-шагового калькулятора сметы и сбора заявок для основателя (`@Nicky_pxl`).

## 🚀 Как запустить бота за 2 минуты:

1. **Получите токен у `@BotFather` в Telegram:**
   - Откройте [@BotFather](https://t.me/BotFather) и отправьте `/newbot` (или возьмите токен уже созданного бота).
   - Скопируйте API-токен вида `1234567890:AAF...`.

2. **Вставьте токен и ваш ID в файл `.env`:**
   - Откройте файл `.env` в этой папке с помощью Блокнота.
   - Замените `YOUR_BOT_TOKEN_HERE` на ваш токен.
   - Узнайте свой цифровой Telegram ID через бота [@userinfobot](https://t.me/userinfobot) и впишите его вместо `0` в строку `ADMIN_ID=` (на этот ID бот будет мгновенно присылать все заявки из калькулятора, прямые заказы и заявки на починку чужих ботов).
   - Поле `FOUNDER_USERNAME=Nicky_pxl` и `CHANNEL_URL=https://t.me/pxlbot_studios` уже настроены!

3. **Запустите бота:**
   - Дважды кликните по файлу `start_bot.bat`.
   - Откройте вашего бота в Telegram и нажмите `/start`!
